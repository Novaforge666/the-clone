# Kivora Markets demo

A single-file, responsive trading landing page inspired by the structure of deriv.com. Open `index.html` directly in a browser or serve it with any static web server. No build step is required.

Kivora Markets is a placeholder brand. The illustrations, market figures, account form, and trading functionality are demonstrations only; no data is submitted and no real trades can be made.

The market snapshot updates locally with simulated values and is explicitly labeled as such. The mobile menu, desktop dropdowns, platform tabs, FAQ, and demo account modal work without a backend. To personalize the page, replace the placeholder name and text in `index.html` and adjust the CSS variables under `:root`.

## Practice trader

Open `index.html#trade` or choose **Try the demo** on the landing page. The dashboard offers simulated markets and chart ranges, a virtual balance, Rise/Fall practice trades, and session-only trade history. Prices and outcomes are generated in the browser, are not live market data, and do not represent a broker or real execution. Nothing is saved or transmitted; reloading resets the session. A production trading application would require an authorized broker integration, secure authentication, a backend, real market data, and applicable regulatory review.
